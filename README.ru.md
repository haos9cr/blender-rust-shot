# Rust Shot — камера для демок Rust в Blender

[English version](README.md)

Аддон для Blender, который позволяет анимировать пролёты камеры для демок **Rust** и проигрывать их в игре.

В игре камерой демки можно управлять только вручную (WASD + мышь). Аддон читает и пишет файлы камеры игры,
поэтому плавные и точные пролёты можно строить в Blender (пути, констрейнты, сглаживание, перевод фокуса)
и отправлять обратно в игру.

Поддерживаются два формата:

| Формат | Версия игры | Что внутри |
|---|---|---|
| **Управление демкой** `demos/controls/<демка>.demo-controls.json` | актуальная (staging, с октября 2026) | Сцены с путём камеры и анимацией **времени суток, солнца, погоды, облаков, тумана, ветра, FOV, фокусного расстояния, DOF и эффектов** |
| **Шот** `.shot` (старый) | старые версии | Позиция, вращение, FOV, DOF камеры |

- Импорт сцены или шота как анимированной камеры; каждый параметр игры становится анимируемым значением
- Экспорт обратно в тот же файл управления; остальные сцены, клоны, источники света и настройки в нём сохраняются
- Файлы игры пишутся ровно так, как их пишет сама игра (проверено байт-в-байт)
- Работает и без Blender: маленькая консольная утилита переводит `.shot` ⇄ JSON

> Неофициальный инструмент. Не связан с Facepunch Studios.
> Форматы файлов восстановлены вручную и могут измениться с обновлениями игры.

## Для удобства: blender-rust-toolkit

[**blender-rust-toolkit**](https://github.com/haos9cr/blender-rust-toolkit) загружает
в Blender карту Rust и её ассеты: рельеф, монументы и постройки видны прямо во время работы. Можно пролетать в дверные
проёмы, скользить над крышами, снимать базу и не врезаться в скалы.
Rust Shot прекрасно работает и без него, toolkit просто помогает видеть, где летит камера.

Анимируются только эти два куба, а камера сама держит горизонт и всегда смотрит на объект.

Как попробовать:
1. Установите **Rust Shot** и откройте `advanced_camera_animation.blend`.
2. Нажмите Play, затем экспортируйте камеру через панель **Rust Shot**.

Загружать карту не обязательно, это просто для удобства: через [blender-rust-toolkit](https://github.com/haos9cr/blender-rust-toolkit)

Самой демки в примере нет. Шот совпадёт только с демкой, записанной на этой карте.

## Установка

1. Скачайте `rust_shot.py`.
2. Blender → **Edit → Preferences → Add-ons → Install from Disk…** (в старых версиях — **Install…**) → выберите `rust_shot.py` → включите **Rust camera shot (.shot)**.
3. В 3D-виде откройте сайдбар (**N**) → вкладка **Rust Shot**.

Проверено на Blender 5.2. Код рассчитан на 3.0+, включая новый API анимации 4.4+/5.x.

## Использование

### Управление демкой (актуальный Rust)

Игра хранит один файл управления на демку в `RustStaging\demos\controls\` (или `Rust\demos\controls\`).
В одном файле может быть несколько сцен.

**Импорт:** панель Rust Shot → **Import controls** (или **File → Import → Rust demo controls**). Можно взять активную
сцену или все сцены, каждая станет камерой. Когда камера выделена, в панели видно:

- **File / Scene** — куда пойдёт экспорт. Сцена с таким именем заменяется, новое имя добавляет сцену в файл.
- **Camera:** FOV, дистанция фокуса (или **Focus Object**), диафрагма — это собственные настройки камеры Blender.
- **Camera / Depth of field / Environment / Effects:** все остальные параметры игры (фокусное расстояние, крен,
  тряска, размытие DOF, время суток, поворот солнца, погода, облака, туман, ветер, bloom, motion blur, виньетка и т.д.).
  Наведите курсор на значение и нажмите **I**, чтобы поставить ключ. **Add control** добавляет параметр, которого в сцене ещё нет.

Время считается в секундах по таймлайну демки: первый кадр диапазона — это **Demo time at start** (по умолчанию 0).

**Экспорт:** поставьте **Format: Demo controls** и нажмите **Export to controls file** (или **File → Export → Rust demo controls**).

| Настройка | Что делает |
|---|---|
| **Path keys / sec** | Ключей пути камеры в секунду. Игра сама сглаживает путь между ключами, хватает 5–10 |
| **Tracks: Keyframes** | Ваши ключи уходят в игру как есть и там остаются редактируемыми. Интерполяция Blender становится режимом ключа: Bezier auto = Smooth, выровненные горизонтальные ручки = Flat, Linear = Linear, Constant = Шаг, свободные ручки = Сломан |
| **Tracks: Bake** | Снимает значения всех анимированных параметров с частотой **Bake keys / sec**: точная форма кривой с любой интерполяцией Blender |
| **Make it the active scene** | Делает экспортированную сцену активной в файле |
| **Backup before overwrite** | Перед записью копирует старый файл в папку `backup` рядом с ним |

Ключи-ступеньки (Constant) пишутся с дополнительным ключом прямо перед скачком, поэтому остаются ступеньками,
даже если игра сгладит кривую. Параметры вкл/выкл, например DOF enabled, всегда экспортируются ступенькой.
Погода: 0 — ясно, 1 — облачно, 2 — дождь, 3 — шторм, 4 — снег.

### Старый формат (.shot)

Настройки ниже (и **Format: Legacy shot**) относятся к файлам `.shot` старых версий игры.

### Импорт
**Панель Rust Shot → Import Rust shot** (или **File → Import → Rust camera shot**).
В настройках импорта выберите FPS сцены (по умолчанию 60). Ключи расставляются так, чтобы скорость в реальном времени сохранилась.

Импортированная камера помнит путь к демке, время старта в демке, папку шота и значения DOF.
Когда камера выделена, всё это можно поменять в панели.

### Экспорт
Настройте экспорт в панели и нажмите **Export to Shots folder** (или **File → Export → Rust camera shot**).

| Настройка | Что делает |
|---|---|
| **Camera** | Активная/выделенная камера, камера сцены, выбор из списка или **все выделенные камеры** (каждая в свой файл с её именем) |
| **Range** | Диапазон сцены, preview-диапазон, ключи самой камеры или свои кадры |
| **Time base** | FPS сцены (как проигрывает Blender) или свой FPS |
| **Speed** | Скорость в игре: `2` — вдвое быстрее, `0.5` — замедленная съёмка |
| **Samples / sec** | Сколько ключей в секунду писать (сама игра пишет около 45). Не зависит от FPS сцены, промежуточные кадры считаются |
| **FOV** | С камеры (анимируется) или постоянное значение |
| **DOF** | Писать глубину резкости, если она включена на камере / всегда / никогда |
| **Shots folder**, **File name** | Куда сохраняет быстрый экспорт; пустое имя — имя камеры |

Перед экспортом панель показывает, **сколько секунд шот будет идти в игре и сколько в нём ключей**.

Камеру можно двигать как угодно: ключи, Follow Path, Track To, родители, драйверы.
В файл записывается итоговое положение в мире.

### Время и FPS
Время в шоте = `(кадр − начало диапазона) / FPS / speed`. Если поменять FPS сцены *после* анимации,
ключи остаются на тех же кадрах, и в игре шот пойдёт быстрее или медленнее. Аддон запоминает,
при каком FPS сделана анимация, и предупреждает, если FPS не совпадает:

- **Rescale keys (keep speed)** растягивает ключи, диапазон кадров и маркеры, сохраняя скорость в секундах.
- **Animation is fine at current FPS** оставляет новую скорость.
- **Change FPS (keep timing)** меняет FPS и сразу пересчитывает ключи.

### Глубина резкости
Треки DOF пишутся, только если при записи в игре включена запись DOF (или при экспорте стоит **DOF = Always**).

| Переменная игры | Blender |
|---|---|
| `graphics.dof_focus_dist` | Camera → Depth of Field → Focus Distance (или расстояние до **Focus Object** вдоль взгляда) |
| `graphics.dof_aper` | Camera → Depth of Field → F-Stop |
| `graphics.dof_blur` | **DOF blur** в панели Rust Shot (анимируется) |

## Система координат

В Rust координаты Unity: X вправо, Y вверх, Z вперёд, левая система. В Blender Z вверх, правая система.

- Позиция: Blender `(x, y, z)` = Unity `(x, z, y)`. Единицы — метры в обоих.
- Вращение: `матрица_камеры_blender = S · R_unity · diag(1, 1, −1)`, где `S` переставляет Y и Z.
  Дополнительный поворот нужен потому, что камера Unity смотрит вдоль +Z, а камера Blender — вдоль −Z.
- Углы дебаг-камеры — это Unity `Quaternion.Euler(x, y, z)` (сначала Z, потом X, потом Y).
- FOV вертикальный, в градусах. У импортированных камер вертикальная подгонка сенсора.

## Консоль (без Blender)

```
python rust_shot.py decode  in.shot  out.json   # посмотреть / поправить как JSON
python rust_shot.py encode  in.json  out.shot
python rust_shot.py roundtrip a.shot b.shot ...  # проверка пересборки байт-в-байт
python tests/test_roundtrip.py                   # проверка всех файлов в samples/
```

Функции можно импортировать и из своего кода: `rust_shot.load(path)`, `rust_shot.save(shot, path)`,
`rust_shot.decode(bytes)`, `rust_shot.encode(dict)`.

## Формат файла

Подробно — в [docs/FORMAT.md](docs/FORMAT.md). Коротко: protobuf-сообщение с именем, путём к демке,
временем старта и длительностью, плюс треки ключей: позиция, вращение (кватернион), FOV и при желании DOF.

`samples/test_orbit.shot` — 10-секундный облёт вокруг начала координат, сделанный в Blender этим аддоном;
проверен в игре. Свои шоты, записанные дебаг-камерой, можно класть в `samples/`:
`tests/test_roundtrip.py` проверяет все файлы в этой папке.

## Известные ограничения

- Управление демкой: стейджинг сейчас загружает все ключи как Smooth, хотя режим ключа сохраняет.
  Если важна точная форма кривой, используйте **Tracks: Bake**. Клоны и источники света сохраняются, но пока не редактируются.
- `.shot`: поле 12 не расшифровано. Это всегда один и тот же маленький блок, он копируется как есть.
- Игра пишет дистанцию фокуса уже сглаженной. Сглаживает ли она её ещё раз при проигрывании — неизвестно.
- Поддерживается только формат шотов дебаг-камеры. Загрузка карты — в [blender-rust-toolkit](https://github.com/haos9cr/blender-rust-toolkit).
